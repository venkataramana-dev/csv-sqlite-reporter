# CSV-to-SQLite Sales Reporter

## Overview
A beginner Python project that imports sales data from a CSV file into an SQLite database and generates a sales report.

## Features
- Read sales records from a CSV file using Python's `csv` module.
- Store sales records in SQLite.
- Prevent repeated imports of the same filename.
- Calculate total sales for each product using SQL aggregation.
- Sort products by total sales in descending order.
- Display formatted sales totals in Indian rupees.
- Handle missing CSV files and invalid numeric values.

## Technologies
- Python
- SQLite
- SQL
- CSV

## Project Files
- `main.py` — application logic and menu.
- `sales.csv` — sample input data.
- `sales.db` — SQLite database generated by the application.
- `README.md` — project documentation.

## How to Run
1. Install Python 3.
2. Open the project folder in a terminal.
3. Run `python main.py`.
4. Choose `1` to import the CSV or `2` to view the report.

## What I Learned
- Reading CSV files with `csv.DictReader`.
- Using SQLite connections and cursors.
- Writing parameterized SQL queries.
- Using `GROUP BY`, `SUM`, and `ORDER BY`.
- Formatting output with Python f-strings.
- Using exceptions and database transactions.

## Current Limitations
The import tracker checks the filename, not whether the file's contents have changed. The database also retains duplicate records created during earlier practice runs.
